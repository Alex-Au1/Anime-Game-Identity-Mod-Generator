Anime Game Identity Mod Generator (AGIDMGen) makes **identity mods**: a mod of a character that looks
**exactly like the character already does in the game**.

An identity mod changes nothing you can see. It is the character's own model, textures and colours, written out as a
mod folder. That makes it the perfect starting point for making your own mod, or for checking that a mod loader works.

A sub-project of `Anime Game Remap (AG Remap)`_.

:raw-html:`<br />`

Requirements
-------------

- Install `Python <https://www.python.org/downloads/>`_ version 3.9 or higher
- An internet connection (the character's files are downloaded for you)

:raw-html:`<br />`

.. tip::
    **Just want the mod?** Every character's identity mod is already made for you in the `Mods`_ folder.
    That page also lists every character's name you can give the generator.
